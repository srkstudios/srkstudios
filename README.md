## Open source

**[Dynamic App Icon Changer](https://github.com/srkstudios/dynamic_app_icon_changer)** lets a Flutter app switch its launcher icon on Android and iOS. A seasonal icon is a small visual change, but the native implementation has to handle scheduled resets, Android activity aliases, and recovery after a device reboot or app update. Those are the details I built the plugin to handle.

[Package and setup guide on pub.dev](https://pub.dev/packages/dynamic_app_icon_changer)
